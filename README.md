Batu Teritip Village Profile Website
This website is the official digital information platform for Batu Teritip Village, Sungai Sembilan District, Dumai City. This project was built to facilitate access to information for the local community and increase transparency in public services at the village level.

Key Features:
Village Profile: Provides in-depth information on the village's history, vision, mission, and organizational structure.

Public Services: Information on administrative procedures and services available to residents.

Regional Map: Geographic visualization of the Batu Teritip Village area to help identify regional boundaries.

News & Activities: The latest updates on village government work programs and community activities.

Regional Potential: Showcasing local strengths, both in the economic sector and natural resources in the local area.

Technology Used:
Frontend: React / Next.js (depending on the framework you use).

Styling: Tailwind CSS for a responsive and modern interface.

Deployment: Vercel for fast and stable access performance.
